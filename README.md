# \## 🌟 Key Features \& Capability Overview

# 

# \### 🎙️ Advanced Audio \& Voice Clean-Up

# \* \*\*Smart Audio Routing:\*\* Choose your specific microphone and speaker directly in settings, featuring a built-in speaker test button.

# \* \*\*Intelligent Voice Normalization:\*\* Automatically balances your volume. It lifts quiet or distant speech, dampens shouting, and preserves the absolute beginning of your phrases so words are never cut off.

# \* \*\*Three Processing Levels:\*\* 

# &#x20; \* \*Standard / Strong:\* Removes deep room rumbles and steady background hums. \*Strong\* mode is specifically optimized for noisy rooms or far-field microphones.

# &#x20; \* \*Off:\* Completely disables voice filtering if maximum raw microphone throughput is preferred.

# \* \*\*Multilingual Accents:\*\* Tell jr.X what languages you speak (e.g., "English, Hindi"). It will dynamically adapt its offline recognition models to expect your accent and mixed-language phrases.

# 

# \### 🤫 Wake Word \& Push-to-Talk (PTT)

# \* \*\*Offline Wake Word:\*\* Simply say \*"hey junior x"\* (or customize the phrase to anything you want) to wake the assistant. Detection runs completely offline locally, ensuring no audio data is transmitted until it is actively awake.

# \* \*\*Push to Talk:\*\* Map a physical key (Default: `F9`) or use the on-screen \*Hold to talk\* button to keep the microphone live only while pressed.

# \* \*\*Flexible Modes:\*\* Keep both switches enabled for hybrid use, or turn both off to leave the assistant in an always-listening state.

# 

# \### 🖥️ The On-Screen Preview Card

# \* \*\*Live Activity Streaming:\*\* When jr.X runs a command or executes research, a compact overlay card appears in the top-right corner of your monitor—even if the main interface is hidden in the system tray.

# \* \*\*Zero Latency Pop-up:\*\* The second jr.X hears structural words like \*research, summarise, terminal,\* or \*run\*, the card forces itself to the front of your active windows to show instant status updates (`Searching...` or `Starting the terminal...`).

# \* \*\*Persistent Window Control:\*\* You can drag the card anywhere on your desktop (including secondary monitors) and drag the bottom-right corner to resize it. jr.X remembers its final position permanently.

# 

# \### 🌐 Desktop \& Browser Autopilot

# \* \*\*Visual Web Navigation:\*\* Drives a dedicated instance of Chrome using its own isolated user profile. It browses, searches, reads web elements, scrolls, and clicks items by sight (e.g., \*"click the red play button"\*). \*Note: The assistant strictly refuses to interact with password fields or credit card numbers for safety.\*

# \* \*\*Virtual Pointer:\*\* Visualizes actions via a custom glowing "jr.X" cursor that moves independently across the screen without interrupting your actual physical mouse.

# 

# \### 📟 Protected Terminal Automation

# \* \*\*Smart System Execution:\*\* Runs local operating system commands seamlessly.

# \* \*\*Built-in Safety Guardrails:\*\* Read-only tasks (`dir`, `git status`, `ping`) execute instantly. Any command attempting to modify files, system settings, or applications will freeze and display a visual prompt detailing exactly what the command does, waiting for your manual confirmation. Dangerous structural commands are blocked outright.

# 

# \### 🧠 Core Memory \& Tools

# \* \*\*Persistent Memory:\*\* View, add, or prune things jr.X explicitly remembers about you over time.

# \* \*\*System Tray Backgrounding:\*\* Choose to let the application run silently in the system tray when closing the primary window. Launch straight to the tray using the "Start hidden" setting.

# \## 🛑 Instant Interruption (Stop System)

# If jr.X is in the middle of a long speech, a complex terminal string, web research, or a desktop task, you can \*\*instantly terminate its actions\*\* by doing any of the following:

# \* Pressing the global \*\*`F8`\*\* hotkey.

# \* Pressing the \*\*`Esc`\*\* key while the main window is focused.

# \* Clicking the \*\*⏹ Stop\*\* button on the UI window or the Preview Card.

# \* Choosing \*\*"Stop what jr.X is doing"\*\* from the system tray icon menu.

# \* Simply speaking the word \*\*"stop"\*\* out loud.
